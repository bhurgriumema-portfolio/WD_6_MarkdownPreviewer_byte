# MarkFlow Studio — Real-Time Markdown Previewer

A modern, responsive Markdown editor that transforms raw Markdown into formatted HTML in real time. Write documentation on the left and instantly preview the rendered result on the right.

**Live Demo:** [MarkFlow Studio](https://markflow-studio.netlify.app/)

**GitHub Repository:** [WD_6_MarkdownPreviewer_byte](https://github.com/bhurgriumema-portfolio/WD_6_MarkdownPreviewer_byte)

---

## Overview

MarkFlow Studio is a browser-based Markdown previewer developed for **B.Y.T.E by Arithmatrix — AVIP 2026, Web Development Task 6**.

The application provides a split-screen workspace where users can write Markdown and see the formatted output instantly. It includes Markdown formatting shortcuts, code syntax highlighting, HTML sanitization, and document export functionality.

The goal is to make writing technical documentation, README files, notes, and code examples easier and more convenient.

## Features

- **Real-Time Preview:** Rendered content updates automatically as the user types.
- **Split-Screen Interface:** Markdown source editor and rendered preview displayed side by side.
- **Markdown Parsing:** Supports headings, paragraphs, bold and italic text, links, lists, tables, blockquotes, and code blocks.
- **Syntax Highlighting:** Uses Highlight.js to style supported code blocks.
- **XSS Protection:** Uses DOMPurify to sanitize generated HTML before displaying it.
- **Formatting Toolbar:** Shortcuts for headings, bold, italic, links, code blocks, and bullet lists.
- **Copy Markdown:** Copy the source document to the clipboard.
- **Export to Markdown:** Download the document as a `.md` file.
- **Clear Editor:** Clear the current document and start fresh.
- **Responsive UI:** Designed to provide a usable editing experience across different screen sizes.
- **Document Statistics:** Displays character and word counts.

## Architecture

MarkFlow Studio follows a client-side rendering workflow.

```text
User types Markdown
        |
        v
React state updates
        |
        v
Marked.js parses Markdown
        |
        v
DOMPurify sanitizes generated HTML
        |
        v
Sanitized HTML is rendered
        |
        v
Highlight.js highlights code blocks
        |
        v
Live Preview updates in the browser
```

### How it works

1. **Input:** The user writes or edits Markdown in the textarea.
2. **State management:** React stores the Markdown content and updates the interface when the content changes.
3. **Parsing:** Marked.js converts the Markdown source into HTML.
4. **Sanitization:** DOMPurify removes potentially unsafe HTML content before it is inserted into the preview.
5. **Rendering:** React displays the sanitized HTML in the preview panel.
6. **Syntax highlighting:** Highlight.js applies syntax highlighting to code blocks after the preview updates.
7. **Document actions:** Users can copy the source Markdown, export it as a file, or clear the editor.

## Security Implementation

User-provided Markdown can contain HTML that may introduce Cross-Site Scripting (XSS) risks if rendered without sanitization.

MarkFlow Studio uses DOMPurify to sanitize the HTML generated by Marked.js before displaying it in the preview.

```js
function renderMarkdown(source) {
  const rawHtml = marked.parse(source, { async: false });

  return DOMPurify.sanitize(rawHtml, {
    USE_PROFILES: { html: true },
  });
}
```

This helps prevent unsafe HTML and event-handler payloads from executing through the rendered preview. Sanitization is an important security layer, although it does not replace broader security testing.

## Getting Started

### Prerequisites

- Node.js installed on your computer
- npm (included with Node.js)
- Git (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/bhurgriumema-portfolio/WD_6_MarkdownPreviewer_byte.git
```

**2. Navigate to the project directory**

```bash
cd WD_6_MarkdownPreviewer_byte
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

### Production Build

To create an optimized production build, run:

```bash
npm run build
```

Vite generates the production files in the `dist` directory.

## Usage

1. Open MarkFlow Studio in your browser.
2. Type Markdown into the source editor.
3. View the formatted result in the live preview.
4. Select text and use the toolbar to apply formatting shortcuts.
5. Use **Copy Markdown** to copy your source.
6. Use **Export .md** to download the document.
7. Use **Clear** to start a new document.

### Example Markdown

```markdown
# Hello World

This is **bold text** and this is *italic text*.

- First item
- Second item

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```
```

The preview automatically renders the Markdown as formatted HTML and highlights supported code blocks.
